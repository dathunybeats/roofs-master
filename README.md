2. **Deploy to Vercel**: [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/roofing-template)
3. **Customize** company details in 5 minutes
4. **Launch** your professional roofing website

## 🎯 Built for Cold Outreach

This template is specifically designed for roofing contractors who want to:
- Create multiple location-based websites quickly
- Generate leads through professional online presence  
- Stand out from competitors with modern design
- Deploy sites for different markets/services

- 📱 **Fully Responsive** - Perfect on all devices

- 📞 **Lead Generation** - Contact forms prominently placed

## 🛠 Tech Stack

- **Next.js 15** - React framework for production
- **Tailwind CSS** - Utility-first CSS framework  
- **Framer Motion** - Smooth animations
- **TypeScript** - Type-safe development
- **Vercel** - Deployment platform
